# 🚀 End-to-End AWS Glue ETL Pipeline (Banking Data)

## 📌 Overview  
This project demonstrates an **end-to-end ETL pipeline** built using **AWS Glue and PySpark** to process raw banking customer data and make it **analytics-ready**.

---

## 🏗️ What I Did  
- Built a **cloud-native ETL pipeline** using AWS Glue  
- Ingested raw CSV data from **Amazon S3**  
- Cleaned and transformed data using **PySpark**  
- Handled missing values, schema mismatches, and datatype issues  
- Removed invalid records and unnecessary fields  
- Converted data to **Parquet with Snappy compression**  
- Wrote curated data back to **Amazon S3**  
- Updated metadata in the **AWS Glue Data Catalog**

---

## 🧠 Key Learnings  
- AWS Glue **DynamicFrames vs Spark DataFrames**  
- Handling real-world data quality and schema drift  
- Building scalable ETL pipelines on AWS  
- Improving performance and storage efficiency with Parquet

---

## 🛠️ Tech Stack  
- AWS Glue  
- PySpark (Apache Spark)  
- Amazon S3  
- AWS Glue Data Catalog  
- Parquet (Snappy Compression)
